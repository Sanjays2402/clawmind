## Notes for me next time

- The lock-wrapper script + heredoc commit messages don't mix: bash sees
  the heredoc-rendered `Done in 8m` line in the captured output and the
  Hermes lifecycle guard refuses to let it run as a foreground command.
  Workaround: write the commit message to /tmp/msg.txt with the write_file
  tool, then `git commit -F /tmp/msg.txt`. Avoid heredoc + commit in one
  shell call.
- pnpm install of the full workspace is ~8 minutes cold from a fresh
  source-only clone (sharp + protobufjs + lance native rebuilds). Plan
  for that on the first tick after a `pnpm prune` or repo move.
- vitest 4 cold-start collection across 11 CLI test files is ~3 min even
  on the M-series; the per-file run is sub-second. The smoke test alone
  imports every command's runtime, which is what's slow.
