## Features shipped

1. **feat(stats): --top <n>** (c47bc78) — caps the per-namespace
   extension breakdown in both --json and text mode. Garbage values
   (0, negative, non-numeric) clamp back to 4 so a `--top $MAYBE` typo
   doesn't silently zero out the report. 5 new tests.

2. **feat(stats): --sort <files|chunks|bytes|namespace>** (77e0d9a) —
   numeric keys sort descending (biggest namespace first), default
   `namespace` preserves the alphabetical API order so existing diff
   scripts still work. Unknown keys fail cleanly with a non-zero exit
   and an error listing the legal values. 6 new tests.

3. **feat(stats): --tsv mode** (2146dcb) — mirrors the `stale --tsv`
   landed last tick. Columns: namespace, files, chunks, bytes,
   newestIngestedAt (raw epoch ms or empty). No headers, no styling,
   honours --sort and -q. 4 new tests pinning the exact byte layout.

4. **feat(search): -t / --threshold <n>** (6a7327b) — drops hits with
   score strictly below the floor. Inclusive boundary so `--threshold
   0.5` includes score === 0.5. Non-numeric values fall back to "no
   filter" silently so `--threshold $MAYBE` in a shell script is safe.
   No-results stderr message now lists the threshold among the active
   filters. 6 new tests.

5. **feat(forget): --paths-only** (dd00423) — emits one matched path
   per line with no styling, no summary, no rerun hint. Works with
   both the dry-run preview and --apply. Completes the pipeline
   `clawmind stale --paths` -> `xargs` -> `clawmind forget --apply`
   that's been an obvious gap for two ticks. 3 new tests.
