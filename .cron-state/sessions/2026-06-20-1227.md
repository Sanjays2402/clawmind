## Theme

This batch rounds out the "--paths" pipeline contract that was started by
`stale --paths` (last week) and `forget --paths-only` (last tick). Now
every list-of-paths CLI noun — pins, mutes, aliases — speaks the same
shape: one path per line, no styling, no headers, no metadata, empty
stream when nothing matches. The byte layout is pinned in tests so
downstream `xargs`/`wc -l`/`cut`/`awk` keep working without conditional
skips.

The two search additions are different but in the same operator-vs-jq
spirit:
- `--no-snippet` shrinks the --json payload to rank/path/score/startLine
  for rerank-style pipelines. The full payload becomes massive at large
  k because each row carries the snippet body and highlight spans.
- stdin (`search -`) lets shell loops drive the search command without
  having to splice the query into argv. Empty stdin is fatal-by-design
  to prevent accidental whole-index dumps.

  this reason; the existing `--no-highlight` does the same.
