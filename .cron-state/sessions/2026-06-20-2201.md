## Theme

Complete two threads the prior ticks had been working toward:

1. **Absolute-date filter family.** Three of the five features add
   `--since <iso-date>` to the three reporting commands that took a
   relative window before: `stats` (newestIngestedAt), `stale`
   (per-file lastIngestedAt derived from ageDays), and `digest show`
   (history ts). Each composes naturally with the existing filters on
   that command. `stats --since` is the namespace-level complement to
   the per-file `stale` command. `stale --since` is the absolute-date
   sibling of `stale --days`. `digest show --since` lets cron answer
   "what did this saved search surface since date Z" without having to
   count history rows by hand.

2. **Paths-only contract finished.** `related --paths-only` was the
   last list-style command missing the pipeline-friendly contract.
   pins, mutes, aliases, tags (--paths) and search, forget, stale
   (--paths-only / --paths) all had it; related did not. Now every
   list-style command emits one path per line on demand, no styling,
   no header, no "no results" hint, with a clean empty stream on zero
   matches. The `clawmind ... --paths | xargs ...` idiom now works on
   every list command in the surface.

3. **One bonus feature pulled from the queued list** — `feedback list
   --above/--below`. The boost filter answers "show me upvote-dominant
   paths" / "strongest downvotes" / "almost-neutral band" with strict
   inequality and intersection semantics.
