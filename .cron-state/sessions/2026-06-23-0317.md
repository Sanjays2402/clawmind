## Design highlights
- **pins/mutes symmetry pinned**: both emit byte-identical {count, paths}
  shape. A multi-user workspace can run the same per-side audit on both
  halves of the pin/mute pair without conditional plumbing. The symmetry
  pin test verifies the key set matches byte-for-byte.
- **tags list uses `tags` not `names`**: the operator already knows these
  are tag identifiers AND `names` would be ambiguous next to
  `tags paths --json --slim` which uses `paths`.
- **tags paths --json --slim is a re-key, not a drop**: the full payload
  is already slim; the slim shape pins the leading-`count` convention
  (count comes last in the full shape).
- **forget --json --slim drops the heaviest fields**: removedPaths array
  (megabytes on a wildcard pattern) AND patterns echo (the caller
  already knows them). ~80 bytes regardless of match count. The dryRun
  boolean is PRESERVED because it disambiguates preview vs apply mode.
- **All five short-circuit --paths-only** (pipeline shape wins).
- **All five silently ignore --slim without --json** (text mode unchanged).
- **All five emit single-line JSON.stringify** for NDJSON-friendly
  snapshot streams.
