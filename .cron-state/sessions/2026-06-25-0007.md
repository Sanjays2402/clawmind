## Critical design notes / bugs caught in-flight

- **MouseEvent footgun (slice 3):** making `submit()` accept an optional
  `question` arg meant the Composer's `<Button onClick={onSubmit}>` would
  have passed a `MouseEvent` as the question, and `q.trim()` would throw on
  the very next Ask click. Fixed to `onClick={() => onSubmit()}`. Easy to
  miss; would have broken the primary button.
- **displayPath vs path 404 (slice 5):** the open-in-viewer deep link must
  use `s.path` (the real filesystem path the `/sources/file` route feeds to
  `readFile`), NOT `displayPath` — which is an alias-shortened LABEL like
  `@notes/foo.md`. Linking by displayPath would 404 every aliased source.
  Verified against apps/api/src/routes/sources.ts before shipping.
- **Citation cycle = cited sources only:** `[` / `]` steps the sources that
  are actually cited in the prose, in order of first appearance — a 12-source
  rail with 3 citations cycles exactly those 3, not all 12. De-dupe via a Set
  so a source cited twice appears once in the cycle.
- **First-pill-only focus id:** only the FIRST pill for a given source carries
  the `cm-cite-<id>` id, so a source cited 3x has a single stable focus target.
- **Skeleton/error mutual exclusion:** an `error` event can arrive before any
  token while `loading` is still true; guarded the skeleton with `!error` so
  the skeleton and ChatError never stack.
- **Three reduced-motion guards:** flash-ring, stream-dot both collapse under
  `prefers-reduced-motion: reduce` (the skeleton already had one).
