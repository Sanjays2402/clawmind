## Critical design notes / decisions

- **Kbd byte-identical (slice 1):** the goal was zero visual change. The two
  size variants (sm flat-muted from CommandPalette, md raised from ShortcutHelp)
  reproduce the exact CSSProperties the local consts had. The TopNav legend was
  a third idiom — one bordered pill wrapping plain mono glyphs — captured as
  `KbdGroup boxed`. Verified all three render identically (typecheck + build).
- **MoreMenu active-trigger highlight (slice 2):** the "More" button itself
  lights up (accent-soft) when the current route is in the secondary set, so a
  user sitting on /pins still sees "where am I" even though Pins is tucked in the
  menu. Reuses the same `pathname === href || startsWith(href + '/')` the nav
  already computes, so highlight + aria-current can't drift. Closes on
  mousedown-outside + Escape + select.
- **dayGroups purity (slice 3):** kept the grouping pure + dependency-free and
  validated it against a 6-row fixture with `pnpm exec tsx` before wiring it in —
  Today/Yesterday/weekday/same-year/older all resolved correctly and input order
  was preserved across + within groups. The history row closure was lifted into
  a local `renderRow()` (function declaration, hoisted) so the ~45-line per-item
  handler block isn't duplicated per group. NOTE: `npx tsx` hung (network fetch);
  `pnpm exec tsx` used the already-installed root devDependency and worked.
- **Stats lens re-rank (slice 4):** switching the metric re-sorts AND rescales,
  so the bars always read "biggest first for this lens". Made the summary stat
  cards (Files/Chunks/Bytes) double as lens shortcuts with an accent ring, tying
  the headline total to the bars below. The 4th card (Namespaces) stays a plain
  div — it has no per-namespace lens, so it has no onClick and renders the
  non-button branch of Stat().
- **Picker is the discoverable twin (slice 5):** deliberately did NOT touch the
  Tab cycling — it stays as fast muscle memory. cmd+/ opens the browsable
  version of the same SAVED_PROMPTS set. Surfaced the binding in three places a
  user looks (footer hint button, ShortcutHelp Chat group, chat breadcrumb) so
  it's actually findable.
