# Design system

ClawMind borrows the Linear and Raycast feel: dark by default, calm contrast, no decorative chrome.

- Font: Geist Sans and Geist Mono.
- Color tokens in `packages/ui/src/styles/tokens.css`.
- Icons are inline Phosphor duotone SVGs, no network fetch.
- Components live in `packages/ui` and are used by `apps/web`.
- Empty, loading, and error states are first-class.
